# Start here for project collaborators

Start with the physical system and the constraints on its fast classical feedback loop.

1. [Information engine](information-engine.md) and [stochastic thermodynamics](thermodynamics.md) explain the bead, trap, measurements, and work.
2. [FPGA and real-time control](fpga.md) connects state estimation and feedback to timing, actuation, and implementation constraints.
3. [IE cost matrix](ie-cost-matrix.md) and [policy-map optimization](optimization.md) explain evaluation and offline synthesis.
4. [QUBO](qubo-ising.md), [Ising mapping](ising.md), [QAOA](qaoa.md), and [coupled policy maps](coupled-policy.md) trace quantum optimization of the same instance.
5. [Benchmarking](benchmarking.md) describes comparisons that support experimental validation. Selected policy maps can be replayed in the IE simulator under held-out conditions.

The shared notebook sequence starts with the [Bell environment check](simulation.md#reproduce-this-step) and continues through notebooks 01?06.
